# CBAY Website

This repository hosts the website for cbay.au.

## Overview

- The website contains an index page, an about page, a blog section, and code projects.
- It is designed to be accessible, navigable, and useful.
- The repository includes assets such as images and external resources.

## Structure

- `index.html`: Main homepage.
- `about.html`: About page.
- `blog/`: Contains blog-related pages.
- `code projects/`: Contains code project demos.
- `links/`: Contains useful links and reading list.
